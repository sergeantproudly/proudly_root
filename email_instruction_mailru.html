Инструкция по установке оформленной E-mail подписи для Mail.ru

  1. Открыть вкладку с исходником сверстанной подписи (пример), нажать сначала Ctrl + A (выделить все), затем Ctrl + C (скопировать)
  2. Перейти по ссылке Общих настроек почты
  3. В секции «Имя отправителя и подпись» килкнуть на иконку карандаша
  4. Установить курсор в поле «Подпись» и нажать Ctrl + V, нажать Сохранить. (не отображаемые картинки — нормальное проявление, на это не обращаем внимание)
